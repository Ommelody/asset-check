# วิธีเชื่อมแอปกับ Google Sheet (ติดตั้งครั้งเดียว ~5 นาที)

แอปตรวจนับครุภัณฑ์จะ **เขียนผลกลับเข้า Google Sheet อัตโนมัติ** ผ่าน Google Apps Script
(จับคู่ด้วยรหัสครุภัณฑ์ในคอลัม B แล้วเขียนลงคอลัม AJ, AK, AL, AM)

## ขั้นตอน

1. เปิด Google Sheet ฐานข้อมูลครุภัณฑ์ของคุณ
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจากไฟล์ **`backend/Code.gs`** ลงไปทั้งหมด
4. ตรวจบรรทัดบนสุด `var SHEET_NAME = 'ALL';` ให้ตรงกับชื่อแท็บชีตที่เก็บข้อมูล (ไฟล์นี้ชื่อแท็บคือ **ALL**)
5. กด **บันทึก** (ไอคอนแผ่นดิสก์)
6. กด **Deploy → New deployment**
   - ไอคอนเฟือง ⚙️ → เลือก **Web app**
   - **Execute as:** `Me` (อีเมลของคุณ)
   - **Who has access:** `Anyone`  ← สำคัญ ต้องเลือกอันนี้แอปจึงจะส่งข้อมูลได้
   - กด **Deploy** → อนุญาตสิทธิ์ (Authorize) ตามขั้นตอน
7. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
8. กลับมาที่แอป → แท็บ **ตั้งค่า** → วาง URL ลงในช่อง แล้วกด **ทดสอบการเชื่อมต่อ**
   - ถ้าขึ้น ✓ เชื่อมต่อสำเร็จ = ใช้ได้เลย ทุกครั้งที่กดบันทึกจะเขียนเข้า Sheet ทันที

## หมายเหตุ
- ถ้ายังไม่ได้ใส่ URL หรือออฟไลน์อยู่ แอปจะ **เก็บผลไว้ในเครื่องก่อน** แล้วค่อยกด "ซิงค์" เมื่อพร้อม — ข้อมูลไม่หาย
- แก้โค้ดแล้วต้อง **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy** ทุกครั้ง URL จึงจะอัปเดต
- คอลัมที่เขียนกลับ: **AJ**=สถานะสติกเกอร์, **AK**=ชั้น, **AL**=แผนก, **AM**=ห้อง
